# Company Profile Website - RevoU SEFC Mini Project

A responsive company profile website built as part of RevoU Software Engineering Fundamentals Course (SEFC) assignment. This project demonstrates fundamental web development skills including HTML structure, CSS styling, JavaScript interactivity, and form validation.

## 📋 Project Overview

This website serves as a company portfolio with the following key features:
- **Dynamic Homepage**: Personalized greeting using JavaScript
- **Company Profile**: Comprehensive information including photo banner, about section, vision & mission
- **Portfolio Section**: Showcase of company headquarters locations
- **Contact Form**: Interactive message form with JavaScript validation

## ✨ Features

- ✅ Responsive design (Desktop & Mobile)
- ✅ Dynamic "Hi [Name]" greeting on homepage
- ✅ Form validation for Message Us section
- ✅ Display submitted form values in HTML
- ✅ Clean and modern UI design
- ✅ Organized file structure
